# ملفات مكتبة حسن يشو

ارفع ملفات PDF العامة إلى `books/`، وأغلفة الكتب بصيغة WebP أو JPG إلى `covers/`. اختر أسماء ملفات ثابتة مثل `book-title.pdf` و`book-title.webp`.

بعد اكتمال نشر GitHub Pages، انسخ رابط PDF إلى خانة رابط الملف، ورابط الغلاف إلى خانة صورة الغلاف في بيانات الكتاب. استخدم رابط `github.io` حتى يفتح الملف مباشرة داخل الموقع.

- [ملف PDF تجريبي](https://abdessamad-bourkibate.github.io/hassan-yachou-library/books/sample-preview.pdf)
- [غلاف تجريبي](https://abdessamad-bourkibate.github.io/hassan-yachou-library/covers/sample-preview.webp)

يضم مجلد `books/` أيضًا نسخًا مطابقة من كتب Google Drive المنشورة. يحتوي `covers/` على صور PNG الأصلية وصور WebP للعرض الأسرع. تُستخدم روابط الملفات الجديدة في معاينة Cloudflare.

الملفات هنا متاحة للزوار. ارفع الكتب والأغلفة التي لديك حق نشرها فقط.
